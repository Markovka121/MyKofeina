**Версия документа:** 1.0. **Дата:** 19.11.2026.

## Бизнес-требования

- BR-1: сократить ошибки при ручном подсчёте стоимости заказа и ускорить его оформление на кассе.
- BR-2: обеспечить бариста актуальным списком готовящихся и выданных напитков в течение смены.
- Показатель результата: время оформления и расчёта одного заказа снижается с 30 секунд (ручной подсчёт) до 10 секунд; количество арифметических ошибок — 0.

## Функциональные требования

- FR-1: система позволяет создать заказ, выбрав напиток из меню и указав количество, с автоматическим расчётом итоговой стоимости и присвоением уникального номера.
- FR-2: система показывает список всех заказов в таблице и позволяет открыть выбранный заказ в форме для просмотра и изменения.
- FR-3: система находит заказ по его номеру и фильтрует список по статусу («Все», «Готовится», «Выдан»).
- FR-4: система позволяет изменить состав/количество заказа и перевести статус: «Готовится» → «Выдан»; обратный переход запрещён.
- FR-5: система удаляет выбранный заказ только после подтверждения пользователя в диалоговом окне.
- FR-6: система автоматически пересчитывает итоговую стоимость заказа при изменении выбранного напитка или его количества.

## Нефункциональные требования и ограничения

- NFR-1: список из 10 записей открывается и обновляется не более чем за 1 секунду на стандартном офисном ПК (CPU 2 ядра, 4 ГБ ОЗУ).
- NFR-2: пустое или некорректное количество (меньше 1, буквы) вызывает понятное окно с ошибкой; заказ не сохраняется.
- NFR-3: поддержка ОС Windows / Linux / macOS с установленным Python 3.8+; читаемый интерфейс на русском языке; проверка ручным тестированием.
- Ограничения: 3 спринта по 2 недели; один разработчик; Python + Tkinter; записи в списке словарей в памяти, без базы данных; сохранение после закрытия не входит в первую версию; демонстрационные вымышленные данные.
- Дополнительно по желанию: экспорт чека или сохранение истории смены в JSON-файл.
- Приоритеты: обязательные — FR-1, FR-2, FR-3, FR-4, FR-5, FR-6, NFR-1, NFR-2, NFR-3; по возможности — сохранение в JSON.
