## Назначение и функции

Система предназначена для сотрудника кофейни (бариста/кассира) для приёма, расчёта и отслеживания выдачи заказов посетителей. Основание — документ `docs/03_Требования.md`.
Обязательные функции:
- FR-1: создание заказа с авторасчётом суммы и присвоением номера.
- FR-2: отображение таблицы заказов и загрузка выбранной строки в форму.
- FR-3: поиск заказа по номеру и фильтрация по статусу.
- FR-4: редактирование состава/количества и перевод статуса «Готовится» → «Выдан».
- FR-5: удаление заказа с подтверждением.
- FR-6: динамический пересчёт цены при выборе напитка или изменении количества.

## Интерфейс

- Интерфейс: одно главное окно Tkinter (`850x550`), разделённое на три блока: форма ввода/редактирования заказа, панель поиска/фильтрации и таблица заказов (`ttk.Treeview`). Выбранная в таблице запись отображается в верхних полях для просмотра и изменения.
- Действия: кнопки «Создать заказ», «Сохранить изменения», «Отметить «Выдан»», «Удалить заказ», «Очистить форму», «Найти», «Сбросить фильтры»; выпадающие списки напитков и статусов; диалоговое окно подтверждения удаления (`messagebox.askyesno`).
- Ошибки: всплывающие окна `messagebox.showerror` и `messagebox.showwarning` при вводе некорректного количества или попытке изменить/удалить невыбранный заказ.
- Макеты: реализованы непосредственно в главном окне `src/main.py`.

## Данные и реализация

- Стек: Python 3 + стандартная библиотека Tkinter (`tkinter`, `ttk`, `messagebox`); внешние библиотеки не требуются.
- Запись (словарь Python): `id` (int), `drink` (str), `qty` (int), `total` (int), `comment` (str), `status` (str).
- Хранение: список словарей Python `self.orders` в оперативной памяти. При запуске список пуст, после закрытия окна записи сбрасываются.
- Правила: допустимые статусы — только «Готовится» и «Выдан»; переход из «Выдан» обратно в «Готовится» заблокирован; количество должно быть положительным целым числом.

## Приёмка

- AT-1 / FR-1, FR-6: выбрать «Латте» (240 ₽), ввести количество «2», нажать «Создать заказ» → сумма рассчитывается как 480, заказ №1 появляется в таблице со статусом «Готовится» → пройдено.
- AT-2 / NFR-2: ввести количество «0» или текст «два», нажать «Создать заказ» → появляется окно с ошибкой, запись не создана → пройдено.
- AT-3 / FR-4: выбрать созданный заказ, изменить комментарий на «Кокосовое молоко», нажать «Сохранить изменения», затем нажать «Отметить «Выдан»» → данные в таблице обновляются, статус меняется на «Выдан» → пройдено.
- AT-4 / FR-3: ввести номер заказа в поле поиска и нажать «Найти» → в таблице отображается только искомый заказ → пройдено.
- AT-5 / FR-5: выбрать заказ, нажать «Удалить заказ» и выбрать «Нет» → заказ остаётся; повторить и нажать «Да» → заказ удалён из списка → пройдено.
- AT-6 / NFR-1: закрыть и заново открыть приложение → список пуст, интерфейс открывается мгновенно (< 1 сек) → пройдено.
- Условия сдачи: все обязательные проверки пройдены; инструкция проверена; приёмку проводит преподаватель.
