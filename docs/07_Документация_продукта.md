## Назначение

Приложение **«MyКофейня»** предназначено для бариста и кассиров кофейни. Оно автоматизирует приём заказов, расчёт их итоговой стоимости по меню, контроль приготовления и выдачу напитков посетителям.

## Установка и запуск

1. Требования: ОС Windows 10/11, Linux или macOS с установленным интерпретатором **Python 3.8 и выше** (включая стандартный модуль `tkinter`). Установка сторонних пакетов не требуется.
2. Скачайте или распакуйте архив с проектом в любую папку на компьютере.
3. Откройте терминал (командную строку) в корневой папке проекта и выполните команду:
   `python src/main.py`
4. Демонстрационные записи для проверки:
   - Заказ 1: Капучино, кол-во `2`, комментарий `Без сахара` (сумма: `440 ₽`).
   - Заказ 2: Раф, кол-во `1`, комментарий `Ванильный сироп` (сумма: `270 ₽`).
   - Заказ 3: Эспрессо, кол-во `3`, комментарий `С собой` (сумма: `450 ₽`).

## Основные сценарии

- **Создать заказ:** выберите напиток в выпадающем списке «Напиток» → введите количество порций в поле «Количество» (сумма пересчитается автоматически) → при необходимости укажите добавки в поле «Комментарий» → нажмите кнопку «Создать заказ». Запись появится в нижней таблице со статусом «Готовится».
- **Найти заказ:** введите номер заказа в поле «Поиск по номеру» и нажмите «Найти», либо выберите нужный статус в выпадающем списке «Фильтр по статусу». Для возврата полного списка нажмите «Сбросить фильтры».
- **Изменить состав или выдать заказ:** кликните по строке заказа в таблице, чтобы его данные загрузились в верхнюю форму. Измените напиток, количество или комментарий и нажмите «Сохранить изменения». Чтобы закрыть заказ после приготовления, нажмите кнопку «Отметить «Выдан»».
- **Удалить заказ:** выберите нужный заказ в таблице → нажмите «Удалить заказ» → подтвердите действие нажатием «Да» во всплывающем окне.
- **Завершить работу:** закройте окно программы стандартной кнопкой закрытия (`✕`). Обратите внимание: в версии 1.0 все заказы хранятся только в оперативной памяти и очищаются после закрытия окна.

## Частые вопросы

- **Запись не добавляется и появляется ошибка.** Проверьте поле «Количество»: там должно быть указано целое число от 1 до 100 без букв и пробелов.
- **Таблица пустая, хотя заказы создавались.** Проверьте панель «Поиск и фильтрация» — возможно, введён номер несуществующего заказа или выбран фильтр «Выдан». Нажмите «Сбросить фильтры».
- **Почему после закрытия программы исчезли все заказы?** В первой версии база данных не используется, информация хранится только во время активной смены (пока открыто окно).
